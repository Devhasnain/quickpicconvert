# QuickPicConvert

[QuickPicConvert](https://quickpicconvert.com) is a free online image toolkit. You can convert, compress, resize, crop, rotate, and watermark pictures right in your browser. There is no sign up, no watermark, and your files stay on your device.

This repository holds the source code of the website at **[quickpicconvert.com](https://quickpicconvert.com)**.

Visit the live site: **https://quickpicconvert.com**

## What You Can Do on QuickPicConvert

QuickPicConvert has 20 image tools. Each tool opens on its own page, so you can go straight to the one you need.

### Convert Images

* [Image Converter](https://quickpicconvert.com/tools/image-converter) changes images between PNG, JPG, and WebP, one file or many at once.
* [Image to JPG](https://quickpicconvert.com/tools/image-to-jpg) turns PNG, WebP, and other pictures into lighter JPG files.
* [Image to PNG](https://quickpicconvert.com/tools/image-to-png) saves your pictures as sharp, lossless PNG files.
* [Image to WebP](https://quickpicconvert.com/tools/image-to-webp) makes smaller images that help your website load faster.
* [JPG to PNG Converter](https://quickpicconvert.com/tools/jpg-to-png) gives you high quality PNG files in seconds.
* [JPG to WebP Converter](https://quickpicconvert.com/tools/jpg-to-webp) shrinks JPG images and keeps great quality.
* [PNG to JPG Converter](https://quickpicconvert.com/tools/png-to-jpg) makes lighter images that upload fast.
* [PNG to WebP Converter](https://quickpicconvert.com/tools/png-to-webp) creates smaller images and keeps transparency.
* [WebP to JPG Converter](https://quickpicconvert.com/tools/webp-to-jpg) makes WebP images open on any phone, app, or website.
* [WebP to PNG Converter](https://quickpicconvert.com/tools/webp-to-png) keeps clear quality so you can use images anywhere.

### Edit Images

* [Compress Image](https://quickpicconvert.com/tools/image-compressor) reduces the size of JPG, PNG, and WebP files with little quality loss.
* [Resize Image](https://quickpicconvert.com/tools/resize-image) sets an exact width and height or a percentage.
* [Crop Image](https://quickpicconvert.com/tools/image-cropper) cuts your photo to any size or aspect ratio with a visual editor.
* [Rotate Image](https://quickpicconvert.com/tools/rotate-image) turns photos 90, 180, or 270 degrees, or flips them.
* [Watermark Image](https://quickpicconvert.com/tools/watermark-image) adds a text or logo watermark with position, size, and opacity controls.

### Developer and Utility Tools

* [Image to Base64](https://quickpicconvert.com/tools/image-to-base64) creates a Base64 string you can copy into HTML, CSS, or JSON.
* [Base64 to Image](https://quickpicconvert.com/tools/base64-to-image) decodes a Base64 string, shows a preview, and lets you download the picture.
* [Image Color Picker](https://quickpicconvert.com/tools/image-color-picker) gets HEX, RGB, and HSL codes from any image.
* [Image to Text](https://quickpicconvert.com/tools/image-to-text) extracts text from photos and screenshots.
* [Image Metadata Reader](https://quickpicconvert.com/tools/image-metadata-reader) shows EXIF details like camera model, date, size, and location.

You can also see every tool on the [all tools page](https://quickpicconvert.com/tools).

## Why People Use It

* **Free.** Every tool is free to use.
* **Private.** Images are processed in your browser and are not uploaded to a server.
* **Simple.** Pick a tool, add your image, and download the result.
* **No account.** You do not need to sign up for anything.

## Tech Overview

The website is built as a modern React web app. Page content for each tool is stored in WordPress and loaded through a GraphQL API. Please update this section so it matches your exact stack and versions.

## Getting Started

Clone the repository and install the packages.

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
npm install
```

Create an environment file and add your WordPress GraphQL address.

```bash
cp .env.example .env.local
```

Start the development server.

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.
